# apps/ — البرامج الخاصة (ملفات ثابتة تعمل في المتصفح)

كل برنامج مجلد مستقل داخل `apps/`. الموقع الجاهز يُجمَّع بأمر واحد ويُنشر على استضافة **محمية بتسجيل دخول**.

```
apps/
  gold-quant/            برنامج الذهب
    src/                 المصادر (تُعدَّل هنا)
    build.py             يبني index.html + version.json
    index.html           الناتج: ملف واحد جاهز (يُرفع إلى git)
    app.json             اسم البرنامج ووصفه للفهرس
  _template/             قالب لبرنامج جديد (فيه اكتشاف الإصدار الجديد)
  build-index.py         يولّد صفحة فهرس تضم كل البرامج
  make-site.py           يجمّع الموقع النهائي في dist-apps/
  stamp-version.py       يختم رقم إصدار لبرنامج من ملف واحد
```

## دورة التحديث الدورية (للمطوّر)

1. نطلب التعديل في جلسة Claude → يُعدَّل `src/` ويُبنى ويُختبر.
2. `python3 apps/gold-quant/build.py` يحدّث `index.html` و`version.json` (الإصدار = `VERSION` + بصمة الكود، فيتغير تلقائياً).
3. الدفع إلى فرع `claude/...` → تنشئ الاستضافة **نسخة معاينة** برابط خاص (للتجربة قبل المستخدمين).
4. الدمج في `main` → تُنشر النسخة الرسمية خلال دقيقة.
5. المستخدم الذي يفتح البرنامج يرى شريط **«يتوفر إصدار جديد — تحديث الآن»** تلقائياً (يفحص `version.json` كل 10 دقائق وعند العودة للتطبيق). بياناته المحلية (الأسعار المخزنة والإعدادات) تبقى كما هي.

برنامج جديد: انسخ `_template/` باسم جديد، أضف `app.json`، وبعد كل تعديل شغّل `python3 apps/stamp-version.py apps/<الاسم>`.

## التشغيل المحلي على جهازك مع تحديث تلقائي (بدون استضافة)

لمن يريد أن يصل كل تعديل يُدفع من جلسة Claude إلى نسخته على جهازه مباشرة:

```bash
git clone https://github.com/VisionAccounting/Vision && cd Vision
git checkout claude/gold-price-forecast-app-j0q271     # أو main بعد الدمج
python3 apps/sync-local.py                              # ويندوز: python apps\sync-local.py
```

ثم افتح `http://localhost:8080/gold-quant/`. السكربت يفحص GitHub كل دقيقة ويسحب الجديد (fast-forward فقط)، والبرنامج المفتوح يعرض شريط «يتوفر إصدار جديد — تحديث الآن» خلال 30 ثانية تقريباً.

- يلزم `git` و`python 3`، وأن يكون جهازك مسجَّلاً في GitHub بحساب له صلاحية قراءة المستودع.
- **ثبّت المنفذ 8080 دائماً**: بيانات المتصفح مرتبطة بالعنوان. النسخة التي كانت تعمل بفتح الملف مباشرة (`file://`) لها مخزن بيانات منفصل، فصدّر منها CSV ثم استورده هنا، أو حمّل التاريخ من تبويب البيانات.
- لا يعمل على الآيفون (لا يشغّل سكربتات). للآيفون استخدم الاستضافة المحمية أدناه.

## الحماية: ما الذي يحمي فعلاً؟

| الطريقة | هل تمنع غير المصرَّح لهم؟ |
|---|---|
| كلمة سر/كود داخل ملف HTML نفسه | **لا.** الملف يصل كاملاً لأي زائر ويمكنه قراءته وتجاوزها |
| GitHub Pages | **لا** (الرابط عام لمن يعرفه، والخاص يحتاج GitHub Enterprise) |
| **Cloudflare Pages + Cloudflare Access** | **نعم** لكنه مصمم لفرق صغيرة (مجاني حتى 50 مستخدماً). **للمشتركين الأكثر من 50 راجع `ARCHITECTURE.md`** |
| Netlify مع حماية بكلمة سر / Firebase Hosting + Authentication | نعم (Netlify الحماية في الخطط المدفوعة) |

التوصية: **Cloudflare Pages + Access**. المستخدم يدخل بإيميل مصرَّح له (رمز يصله على بريده أو حساب Google/Microsoft)، وتتحكم أنت بالقائمة.

### الإعداد لمرة واحدة (Cloudflare)
1. Cloudflare → Workers & Pages → Create → Pages → Connect to Git → اختر المستودع.
2. Build command: `python3 apps/make-site.py dist-apps` — Build output directory: `dist-apps` — Production branch: `main`.
3. Zero Trust → Access → Applications → Add → Self-hosted → النطاق (مثل `apps.example.com` أو `*.pages.dev` الخاص بالمشروع، مع نطاقات المعاينة `*.<project>.pages.dev`).
4. Policy: Allow → Emails (أو Emails ending in `@شركتك.com`) أو One-time PIN.
5. أضف المستخدمين بإضافة إيميلاتهم لسياسة الدخول؛ وإزالة إيميل تسحب الوصول فوراً.

## حدود يجب معرفتها

- **كود البرنامج يصل لمتصفح كل مستخدم** (حتى مع الحماية). الحماية تمنع غير المصرَّح لهم، لا تخفي الكود عن المصرَّح لهم.
- **بيانات كل مستخدم محفوظة على جهازه** (`localStorage`)، لا يراها غيره ولا ترفع إلى أي خادم.
- **جلب الأسعار** يتم من متصفح كل مستخدم عبر وسطاء CORS مجانية (cors.lol وcorsproxy.io وallorigins وcodetabs). مع عدد مستخدمين أكبر ستتأخر أو تُقيّد. الحل الإنتاجي: وسيط خاص (Cloudflare Worker) يحصر المواقع المسموحة ويخزن الاستجابة دقيقة فيُجلب السعر مرة واحدة لكل المستخدمين.
- إذا كانت «شروط الدخول» اشتراكاً مدفوعاً أو ترخيصاً لكل مستخدم، فهذا يحتاج خدمة دفع وخادم تحقق (Stripe مثلاً) بعد الحماية أعلاه.

## التثبيت على الآيفون
